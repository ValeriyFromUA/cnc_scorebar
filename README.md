# 🎖️ Scorebar — оверлей рахунку для CnC Generals: Zero Hour

Настільний оверлей-скорбар для трансляцій матчів **Command & Conquer: Generals — Zero Hour**: рахунок, гравці, фракції, прапори країн і ELO — поверх гри або як окреме джерело в OBS. Працює на **Windows** і **macOS**.

> Зроблено в Україні — FROM_UA 🇺🇦

---

## ✨ Можливості

- **Режими матчу**: командний (1v1 … 4v4) та FFA (2–8 гравців, автосортування за рахунком).
- **Гравці**: нік, країна (прапори за алфавітом, Україна перша, є піратський 🏴‍☠️), фракція/генерал з оригінальними іконками гри, колір гравця.
- **ELO та дивізіони**: список гравців автоматично підтягується з [cnc-general-ukraine.org](https://www.cnc-general-ukraine.org), ELO можна перебити вручну для кожного гравця.
- **11 тем оформлення**: CnC Generals, Neon/Cyberpunk, Crysis 3, Witcher 3, Brushed Steel, Carbon, Frosted Glass, Terminator T-800, Control FBC, Токсична зона, Чорний кіт, Half-Life HEV — кожна зі своєю формою рамки та палітрою.
- **Маркер кольору гравця**: трикутник, лінія під ніком або зафарбований край картки.
- **Гнучке налаштування**: розміри шрифтів (рахунок / ніки / заголовок / ELO), відступи між рядками та від рамки, заголовок турніру на тематичній підкладці (можна вимкнути).
- **Мультимонітор**: вибір екрана для оверлею, позиція зверху/зліва/справа.
- **OBS-friendly**: звичайне вікно із заголовком "Scorebar Overlay" — легко знаходиться у Window Capture; "завжди зверху" опційно.
- **Автозбереження**: всі налаштування зберігаються у `scorebar_config.json` і відновлюються при запуску; конфіги можна зберігати/завантажувати окремими файлами.
- Панель керування **не перехоплює клавіатуру**: жодних глобальних гарячих клавіш, ввід працює лише в полях самої панелі.

## 🚀 Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python control_panel.py
```

Відкриються два вікна: **оверлей** (його захоплює OBS) і **панель керування** з вкладками «Гра» (режим, гравці, рахунок) та «Дизайн» (тема, шрифти, відступи, позиція, монітор).

### Збірка під Windows

```bat
build_windows.bat
```

Готовий `.exe` збирається через PyInstaller (також є GitHub Actions workflow `build-windows.yml`).

## 🎥 Порада для OBS

«Завжди зверху» вмикати **не потрібно** — OBS сам компонує джерело в сцені. Просто додайте джерело *Window Capture* і виберіть вікно **Scorebar Overlay**.

## 📝 Чейнджлог

### v1.4 — 2026-07

**Панель керування**
- 🗂️ Дві вкладки: **«Гра»** (режим, карта, гравці, рахунок) і **«Дизайн»** (все про вигляд).
- 🖥️ Вибір монітора для оверлею (Windows і macOS, список оновлюється наживо).
- 📐 Інтерфейс розтягується разом із вікном — і по ширині, і по висоті.
- 🧾 У командному режимі команди йдуть одна під одною — панель не ширша за FFA.
- ⌨️ Ручний ввід ELO для кожного гравця — перебиває скачане з сайту (скачане видно в плейсхолдері).
- 🎨 Кольори гравців — компактними квадратиками без тексту.
- 📋 У випадаючому списку гравців — лише ніки.

**Скорбар**
- 📏 Ширина динамічно підлаштовується під найдовший нік; ніки завжди по центру і не обрізаються.
- 🎯 Рахунок строго по центру своєї панелі; при зміні ширини розширюються бокові панелі, а центр стоїть на місці.
- 🔤 Регулювання розмірів шрифтів: рахунок, ніки, заголовок, ELO.
- ↕️ Налаштування відступів: між рядками гравців і від рамки до ніків.
- 🖍️ Три режими маркера кольору гравця: трикутник, лінія під ніком, зафарбований край (трикутник з основою на самому краю картки, повторює форму рамки).
- 🏷️ Заголовок на тематичній підкладці, з перемикачем показу.
- ➖ Прибрано надпис режиму (1v1/2v2) і дивізіон — лишилось тільки ELO.
- 🌍 Країни за алфавітом (Україна перша) + піратський прапор 🏴‍☠️.
- 🖼️ Порожній рядок карти більше не займає місце.
- 🎖️ Оригінальні іконки генералів і армій з гри (3 кольорові варіанти) замість мальованих бейджів.
- 🚩 Прапори країн — PNG замість емодзі (Windows показував емодзі-прапори як літери).
- 📺 Виправлене захоплення вікна в OBS: оверлей — звичайне вікно "Scorebar Overlay", видиме у Window Capture.

**Сумісність (окрема вкладка)**
- 🟩 Суцільний фон замість прозорого (чорний / зелений / магента під хромакей) — для старих методів захоплення (BitBlt), які не знімають напівпрозорі вікна Windows; вікно при цьому отримує маску за формою скорбару, тож фон не вилазить за його межі.
- 🔝 Чекбокс "Завжди зверху" перейменовано на "Поверх усіх вікон" з докладним тултіпом.
- ✨ Перемикач вимкнення світіння (glow) — проти артефактів і просідань FPS на слабших машинах.
- 🔤 Шрифти з повним ланцюжком фолбеків — на Windows без Eurostile коректно підхоплюються Arial Narrow / Segoe UI.
- 💾 Конфіг зберігається поруч з exe (а не в довільній робочій теці ярлика); якщо тека тільки для читання — у `%APPDATA%\Scorebar`.
